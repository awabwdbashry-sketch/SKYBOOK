# ✈️ SKYBOOK — منصة حجز الرحلات الفاخرة

> **السفر الفاخر بين يديك ✦**

**SKYBOOK** هو مشروع واجهة ويب عصرية وفاخرة لحجز واستكشاف الرحلات الجوية، تم تصميمه بتجربة مستخدم عربية بالكامل **RTL** مع تركيز كبير على التفاصيل البصرية، الحركات التفاعلية، وسهولة استخدام نموذج البحث عن الرحلات.

المشروع يجمع بين تصميم سينمائي حديث وتجربة حجز متكاملة من ناحية الواجهة، مع أقسام للوجهات، العروض، آراء العملاء، الأسئلة الشائعة والتواصل.

# ✈️ SKYBOOK — Premium Flight Booking Platform

> **Luxury travel at your fingertips ✦**

**SKYBOOK** is a modern premium web interface for discovering and booking flights. The project is designed with a fully Arabic **RTL** user experience and focuses heavily on visual quality, interactive components, animations, and a smooth flight-search experience.

The website combines a cinematic aviation-inspired design with interactive sections for destinations, deals, customer reviews, FAQs, and contact.

---

## 🌟 Features

### ✈️ Flight Search Experience

- Search flights between cities and airports.
- Multiple trip types:
  - Round trip.
  - One way.
  - Multi-city.
- Swap departure and destination locations.
- Departure and return date selection.
- Passenger selection.
- Adults, children, and infants support.
- Airport and city autocomplete suggestions.
- Airport codes such as `CAI`, `DXB`, and `JED`.
- Automatic default date configuration.
- Interactive search feedback.

### 🌍 Destinations

- Worldwide destination cards.
- Interactive destination components.
- Subtle parallax hover effects.
- Quick destination selection.

### 🎟️ Flight Deals

- Featured travel deals.
- Interactive deal cards.
- Booking interaction buttons.
- Toast notifications for user actions.

### ⭐ Customer Reviews

- Interactive testimonial slider.
- Automatic slide playback.
- Previous and next controls.
- Navigation dots.
- Keyboard navigation.
- Touch swipe support for mobile devices.

### ❓ FAQ

- Interactive FAQ accordion.
- Expand and collapse answers.
- Automatically closes other open questions.

### 📩 Contact Form

- Interactive contact form.
- Loading state.
- Success state.
- Automatic form reset.
- Toast confirmation messages.

### 🎨 Premium UI

- Premium loading screen.
- Loading progress indicator.
- Glassmorphism components.
- Cinematic hero section.
- Animated SVG airplane.
- Floating particles.
- Hero sparkles.
- Hover effects.
- Scroll reveal animations.
